Liderei o desenvolvimento full-stack de um site institucional para uma empresa fintech em um projeto remoto.

- Conectei Drupal headless e uma API GraphQL a um frontend Nuxt de geração estática.
- Implementei internacionalização com i18n e estilos com Tailwind CSS.
- Desenvolvi um [módulo de extração de imagens para Nuxt](https://github.com/d1urno/nuxt-image-extractor) de código aberto para o fluxo de geração estática.
